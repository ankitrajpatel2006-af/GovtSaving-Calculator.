# 💰 GovtSave Calculator

GovtSave Calculator is a free, browser-based financial planning website designed to help users estimate returns, maturity values, and contributions for popular Indian government savings and retirement schemes.

## 🌐 Live Demo

https://ankitrajpatel2006-af.github.io/GovtSaving-Calculator./

## ✨ Features

- 📊 Government savings and investment calculators
- 📈 Interactive calculation results
- 📄 PDF report generation
- 📚 Scheme-specific educational guides
- 🔄 Comparison and planning tools
- 📱 Responsive design for mobile and desktop
- ⚡ Browser-based — no backend required
- 🔒 No user account or login required

## 🧮 Available Calculators

The project currently includes calculators for:

- Sukanya Samriddhi Yojana (SSY)
- Public Provident Fund (PPF)
- Post Office Monthly Income Scheme (POMIS)
- National Pension System (NPS)
- Senior Citizens Savings Scheme (SCSS)

## 📚 Educational Guides

The project also includes dedicated guides covering:

- SSY
- PPF
- POMIS
- NPS
- SCSS
- Scheme comparison and planning

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Client-side PDF generation
- Responsive web design

## 🚀 How to Use

1. Open the live website.
2. Select the required calculator.
3. Enter the relevant values.
4. View the estimated results.
5. Generate a PDF report when available.
6. Use the guides to understand the respective scheme.
